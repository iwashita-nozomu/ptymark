# ptymark v0.1.0-alpha.5

`v0.1.0-alpha.5` is a source-only prerelease focused on one bounded interactive control: pausing and
resuming semantic rendering inside the current Ptymark session without changing persistent
configuration or restarting the child shell.

## Highlights

- Adds a session-local rendering toggle for native Unix PTY and Windows ConPTY sessions.
- Adds an append-only WezTerm binding, defaulting to `CTRL|SHIFT|ALT+R`.
- Keeps the transient state inside the current Ptymark process; a new session starts enabled and no
  TOML, installation state, shell profile, prompt, or WezTerm file is modified at runtime.
- Restores detector-retained partial source before entering passthrough.
- Resumes only at a valid logical-line boundary, preventing a key press in the middle of a line from
  manufacturing a false Mermaid, TeX, or OpenMath opener.
- Preserves all terminal-control and alternate-screen safety classification while rendering is paused.
- Proves the transition with real Unix PTY and Windows ConPTY children and an executable WezTerm Lua
  smoke contract.

## Use the toggle in WezTerm

The shipped example appends two bindings:

```text
CTRL|SHIFT+P       open a new Ptymark-hosted tab
CTRL|SHIFT|ALT+R   pause or resume rendering in the active Ptymark session
```

Inside a normal render-capable session, the first press makes subsequent complete semantic blocks
appear as exact source. The second press resumes the original policy.

Customize or disable the toggle without replacing existing keys:

```lua
ptymark.apply_to_config(config, {
  render_toggle_key = { key = 'T', mods = 'CTRL|ALT' },
})
```

```lua
ptymark.apply_to_config(config, {
  render_toggle_key = false,
})
```

The WezTerm binding applies to the active pane. Use it inside a Ptymark-hosted session; outside
Ptymark, WezTerm would send the reserved private-use scalar to that pane's foreground application.

## Behavioral boundary

- A renderer already executing when the key is pressed may finish.
- The new state is observed before the next safe output boundary.
- A partially detected block is restored as exact source when rendering is paused.
- If rendering resumes in the middle of a line, passthrough continues through the next newline before
  detection restarts.
- The toggle suppresses but never expands the baseline policy. `--source` and `--safe` remain
  non-rendering; `--private` never regains a cache.
- Only the UTF-8 encoding of private-use scalar `U+10FFFD` is reserved. Partial or mismatching
  prefixes return byte-for-byte, and Escape is forwarded immediately. Apart from that value, Ctrl+C,
  bracketed paste, mouse reports, ordinary escape sequences, and normal keyboard bytes remain child input.
- No status text is injected into the child stream or prompt.

## Install from the released source

```bash
git clone --branch v0.1.0-alpha.5 https://github.com/iwashita-nozomu/ptymark.git
cd ptymark
bash scripts/installer.sh
```

Then verify:

```bash
ptymark --version
ptymark install status
ptymark config check
ptymark engine check
ptymark doctor
```

On Windows, use the documented PowerShell, cmd.exe, or Windows-Bash source-install route.

## Source-only distribution

This release intentionally contains no project-uploaded executable archives, installer bundles,
renderer bundles, binary checksums, binary manifests, attestations, or executable-bearing artifacts.
GitHub provides the immutable tag, these notes, and its generated source snapshots only.

Local builds and third-party packages are not automatically trusted or endorsed. Review the tag,
lockfiles, toolchain, dependencies, and downstream packaging channel appropriate to the environment.

## Verification model

- Rust formatting, Clippy with warnings denied, and tests run on Ubuntu, macOS, and Windows.
- Input-filter tests cover every `U+10FFFD` byte split, mismatch recovery, EOF prefixes, immediate Escape, and
  repeated toggles.
- Pipeline tests cover pause, exact partial-source restoration, resume, and mid-line safety.
- Real Unix PTY and Windows ConPTY tests verify that one block renders before the toggle and the next
  complete block returns as source without leaking the control sequence to the child.
- The WezTerm Lua smoke contract verifies default, custom, invalid, and disabled bindings while
  preserving existing key and launch-menu entries.
- Canonical Docker, installers, managed renderers, shell coexistence, CodeQL, dependency review,
  dependency alignment, package smoke, and source-only release metadata remain independent gates.

## Roadmap

The broader guided-setup, effective-state discovery, CJK/grapheme, accessibility, and text-first
usability work previously proposed for Alpha.5 is now tracked for `v0.1.0-alpha.6`. Beta.1 remains
after that adoptability release and retains lifecycle completion, public-contract freeze, and the
minimum copyable structured-artifact boundary.

## Known limitations

- This remains an alpha release.
- A renderer already in flight may complete after the key press.
- The transient state is not persisted or exposed as child environment state.
- The release does not add guided setup, complete CJK/grapheme/accessibility behavior, lifecycle
  commands, persistent workers/cache, approved signed package channels, structured copy actions, or
  terminal image protocols.
